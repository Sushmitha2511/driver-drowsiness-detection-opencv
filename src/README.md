# Driver Drowsiness Detection using OpenCV

A real-time driver drowsiness detection system developed using Python and OpenCV to improve road safety through facial landmark analysis.

## Features
- Real-time face detection
- Eye and mouth monitoring
- Drowsiness alert system
- Webcam-based monitoring
- Works under different lighting conditions

## Technologies Used
- Python
- OpenCV
- Dlib
- NumPy

## How It Works
The system continuously captures video frames using a webcam and analyzes facial features such as eyes and mouth. Eye Aspect Ratio (EAR) and Mouth Aspect Ratio (MAR) are used to detect signs of drowsiness and trigger an alarm.

## Applications
- Advanced Driver Assistance Systems (ADAS)
- Road safety systems
- Smart vehicle monitoring
