A real-time Driver Drowsiness Detection System developed using Python and OpenCV to improve road safety through facial landmark analysis and fatigue monitoring.

---

## Overview

Driver fatigue is one of the major causes of road accidents worldwide. This project focuses on detecting driver drowsiness in real time using computer vision techniques. The system continuously monitors the driver's facial features such as eyes and mouth using a webcam and alerts the driver when signs of fatigue are detected.

The project was developed as part of research work in the domain of Advanced Driver Assistance Systems (ADAS).

---

## Key Features

- Real-time driver monitoring
- Eye Aspect Ratio (EAR) based detection
- Mouth Aspect Ratio (MAR) analysis
- Fatigue alert system
- OpenCV-based facial landmark detection
- Works under different lighting conditions
- ADAS-focused implementation

---

## Technologies Used

- Python
- OpenCV
- Dlib
- NumPy
- Imutils
- Scipy

---

## System Workflow

1. Capture real-time video using webcam
2. Detect driver's face and facial landmarks
3. Calculate Eye Aspect Ratio (EAR)
4. Analyze mouth movements and fatigue indicators
5. Trigger alert when drowsiness is detected
